# Companion agent skills（可选）

These are the author's own agent-workflow skills (for ZCode `.zcode/skills/` or as Cursor commands). They teach an AI agent to drive this plugin's bridge protocol end-to-end:

- **novel-review** — deep review & fix workflow for the novel vault (`/novel-review 审核|整改`)
- **dev-review** — dev delivery review workflow (`/dev-review 需求|交付|继续|状态`)

They are examples/templates: copy them into your own `.zcode/skills/` (ZCode) or `.cursor/commands/` (Cursor) and adjust paths to your vault. The plugin itself works with any agent that follows the bridge protocol documented in the main README.
