description: 把外部接口资料规范化成接口文档总汇（接口摄取 <来源> [服务名]）
---

把外部接口资料（网页 / 表格 / txt / word / 粘贴）规范化成 `docs/接口文档/<服务>/_接口.md` 总汇：网页用抓取能力取正文（需登录的请作者另存 / 粘贴），本地文件任意格式（office / pdf 先转文本）；缺失字段填「暂无」，接口名称/说明/HTTP Method 可从函数名或上下文推断、逐条经作者确认后写入；响应 JSON 一律格式化（```json 代码块、每字段一行）；原始快照存 `_源.<ext>`，并更新 `_索引.md`。

先加载并遵守技能 dev-review 的 SKILL.md：优先项目级 `.cursor/skills/dev-review/SKILL.md`（ZCode 为 `.zcode/skills/`），没有则读用户级 `~/.cursor/skills/dev-review/SKILL.md`（ZCode 为 `~/.zcode/skills/`）。

执行 dev-review 的子命令「接口」，动作 `摄取`，参数：$ARGUMENTS

按技能执行，不要往仓库写模板文件。开发文档固定写在 `docs/开发文档/<模块>/`。
